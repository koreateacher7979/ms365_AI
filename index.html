Module 1

M365 A3 라이선스와 기본 활용

교육용 M365 환경의 이해와 실무 적용 방법

M365 A3 라이선스의 핵심 특징

  • 프리미엄 데스크톱 앱: Word, Excel, PowerPoint 등을 웹과 PC에 설치하여 완벽히 활용 가능.
  • 안전한 클라우드: 넉넉한 OneDrive 용량 제공 및 Teams를 통한 파일 실시간 공동 작업 지원.
  • 엔터프라이즈 데이터 보호(EDP): 교사와 학생의 데이터, 프롬프트는 외부 AI 모델 학습에 절대 사용되지 않아 안전합니다.

교육 현장 적용 방안

행정 업무 효율화

OneDrive 문서 공유를 통해 동학년 교사 간 기안문, 평가표 등을 실시간으로 동시 작성하여 취합의 번거로움을 줄입니다.

스마트 교실 연동

Teams를 활용하여 온라인 과제 배포, 수합 및 학생 간 협업 프로젝트 환경을 원스톱으로 구성합니다.

실습 전 확인사항: microsoft365.com에 로그인 후 우측 상단 또는 좌측 메뉴에 Copilot 아이콘이 정상적으로 보이는지 확인해 주세요.
Module 2

Copilot M365 앱 연동 실습

Word와 Outlook에서 생성형 AI를 활용한 문서 초안 작성 및 맞춤형 이메일 소통

[실습 1] Word - 가정통신문 작성

  1. 빈 Word 문서를 엽니다.
  2. 본문 좌측에 나타나는 Copilot 아이콘을 클릭합니다.
  3. 아래 프롬프트를 복사하여 붙여넣고 실행합니다.

너는 중학교 담임교사야. 다음 주 금요일 오후 2시에 학교 강당에서 열리는 '학부모 대상 디지털 리터러시 특강' 안내 가정통신문 초안을 작성해 줘. 학부모님들이 부담 없이 참석할 수 있도록 친절한 어조로 작성하고, 맨 아래에는 참석 여부를 회신할 수 있는 [절취선] 양식을 만들어 줘.

[실습 2] Outlook - 안내 메일 초안 작성

  1. 웹 브라우저에서 Outlook을 열고 새 메일을 클릭합니다.
  2. 메일 본문 입력창 도구 모음에서 Copilot 아이콘(초안 작성)을 클릭합니다.
  3. Word에서 작성한 내용을 바탕으로 학부모님들께 보낼 요약 안내 메일 프롬프트를 실행합니다.

앞서 기획한 '학부모 대상 디지털 리터러시 특강' 안내를 학부모님들께 이메일로 발송하려고 해. 메일 제목을 시선을 끌 수 있게 작성하고, 본문은 바쁜 학부모님들이 핵심(일시, 장소, 목적)만 빠르게 파악할 수 있도록 글머리 기호를 사용하여 요약해 줘. 마지막에는 참석을 독려하는 따뜻한 인사말을 덧붙여 줘.

Module 3

데이터 구조화로 맞춤형 에이전트 만들기 (MD)

파일 업로드 제약을 넘어, 마크다운(MD) 변환으로 복합 데이터를 에이전트에 주입하기

A3 환경의 제약 극복: 에이전트에 파일 업로드가 안 된다면?
👉 Copilot 채팅에서 '이미지 캡처본 + 텍스트 데이터'를 한 번에 MD 코드로 변환하여 에이전트 지침에 텍스트 형태로 직접 주입하면 완벽히 해결됩니다!
예시 1 (Fun)

나의 취향과 카톡 말투를 합친 '아바타 AI'

쇼핑몰 장바구니 캡처본과 카톡 대화 발췌본을 동시에 분석하여 입체적인 페르소나 MD 데이터를 만듭니다.

  1. 일반 Copilot 채팅창을 열고 장바구니 캡처 이미지를 첨부합니다.
  2. 아래 프롬프트를 복사하여 실행합니다. (카톡 대화 샘플이 포함되어 있습니다.)

첨부된 [장바구니 이미지]와 아래 제공된 나의 [카톡 대화 샘플]을 융합 분석해서 나를 복제해 줘. [나의 카톡 대화 샘플] "오키오키 확인! 아니 근데 진짜 대박 ㅋㅋㅋ 오늘 점심 뭐먹지? 그치그치 완전 공감, 난 돈까스! 넵! 바로 처리할게요~ 👍" 분석한 '나의 소비 성향'과 '자주 쓰는 말투/이모티콘' 패턴을 표로 정리해 줘. 중요: 내가 에이전트에 쉽게 복사해 넣을 수 있도록, 결과물은 시각적인 표로 그리지 말고 반드시 **마크다운 코드 블록(```markdown ... ```)** 안에 텍스트로만 출력해 줘.

👉 생성된 MD 복사 후 새 에이전트 지침(Instructions)에 입력:

너는 아래 [나의 페르소나 MD 데이터]를 학습한 내 클론 AI야. 누군가 질문하면 기계처럼 답하지 말고 내 '카톡 말투'를 그대로 흉내 내서 대답해. 선물이나 맛집을 추천할 때는 내 '소비 성향'을 적극 반영해 줘. [나의 페르소나 MD 데이터] (⚠️ 여기에 추출된 마크다운 코드 블록을 붙여넣으세요!)

예시 2 (Work)

나만의 '수행평가 자동 채점 및 피드백 AI' 만들기

줄글로 작성된 거친 '평가 기준표(루브릭)'를 MD 표로 구조화하여 에이전트의 지침에 고정합니다. 이후 학생들의 답안만 반복 입력하면 기준에 맞춰 일관성 있게 채점하는 완벽한 재사용 에이전트를 완성합니다.

  1. 일반 Copilot 채팅창에 아래 프롬프트를 입력하여 평가 기준을 MD 코드로 변환합니다.

아래 메모해 둔 [과학 에세이 평가 기준]을 분석하기 좋은 마크다운 표로 정리해 줘. 열(Column)은 [평가 항목, 상(A), 중(B), 하(C)]로 구성해 줘. 반드시 복사하기 쉽게 **마크다운 코드 블록(```markdown ... ```)** 안에 텍스트로만 넣어줘. [과학 에세이 평가 기준] 논리성은 주장이 명확하고 근거가 타당하면 상, 주장은 있는데 근거가 부족하면 중, 둘다 안되면 하. 표현력은 과학 용어 3개 이상 쓰면 상, 1~2개면 중, 없으면 하. 분량은 500자 이상 상, 300자 이상 중, 미달이면 하.

👉 생성된 MD 복사 후 새 에이전트 지침(Instructions)에 입력:

너는 우리 학교의 공정한 '수행평가 채점 보조 AI'야. 아래 [평가 기준 MD 표]를 엄격하게 적용하여, 내가 앞으로 입력할 '학생의 에세이 답안'을 평가해 줘. 평가 결과는 각 항목별 등급(A/B/C)과 총평, 그리고 학생을 위한 따뜻한 피드백으로 구성해 줘. [평가 기준 MD 표] (⚠️ 여기에 추출된 마크다운 코드 블록을 붙여넣으세요!)

테스트: 에이전트가 완성되면 우측 테스트 창에 "학생 답안: 지구온난화는 심각합니다. 왜냐하면 북극곰이 살 곳이 없어지기 때문입니다. (150자)" 라고만 입력해 보세요. 에이전트가 저장된 기준표를 바탕으로 즉시 채점해 줍니다!
Module 4 (심화)

한계 돌파! Studio로 다중 파일 기반 에이전트 구축

Copilot Studio의 로컬 파일 다중 업로드 기능을 활용하여 강력한 커스텀 지식망 만들기

강력한 Studio의 지식 베이스:
A3 기본 에이전트와 달리, Studio에서는 여러 개의 로컬 파일(.txt, .pdf, .docx 등)을 동시에 업로드하여 지식으로 삼을 수 있습니다. 방대한 양의 개인 데이터나 학교 규정집 등을 조합하기에 최적의 환경입니다.
예시 1 (Fun)

나의 완벽한 딥러닝 클론 (카톡 + 쇼핑 리스트)

카톡 대화 백업 파일(.txt)과 위시리스트 문서(.docx)를 동시에 업로드하여 나의 모든 것을 아는 AI를 만듭니다.

  1. Copilot Studio 접속 후 '새 Copilot' 생성.
  2. 지식(Knowledge) 탭에서 아래 두 가지 파일을 동시에 업로드합니다.
    • PC 카카오톡에서 내보낸 대화내용.txt 파일
    • 내가 좋아하는 관심사/쇼핑 목록을 적은 나의위시리스트.docx 파일
  3. 지침(Instructions)에 아래 내용을 복사하여 넣습니다. (본인 이름 수정)

너는 업로드된 [대화내용.txt]와 [나의위시리스트.docx]를 완벽하게 학습한 '나의 완벽한 디지털 클론'이야. 업로드된 카톡 파일에서 [본인 이름 입력] 이라는 화자의 말투, 이모티콘 사용법을 흉내 내어 진짜 나처럼 리얼하게 대답해야 해. 누군가 나에게 줄 선물을 물어보거나 주말 계획을 물어보면, 반드시 [나의위시리스트.docx]의 취향과 관심사를 기반으로 답변을 구성해 줘.

예시 2 (Work)

학교 규정 및 학사일정 마스터 AI

학교의 방대한 내부 규정집과 연간 학사일정 PDF를 업로드하여, 교직원과 학부모의 질문에 즉각 대응하는 챗봇을 구성합니다.

  1. 지식(Knowledge) 탭에 학교 공식 문서 파일들(예: 2026_학사일정.pdf, 학교생활규정.pdf)을 다중 업로드합니다.
  2. 지침(Instructions)에 아래 내용을 복사하여 넣고 권한을 설정합니다.

너는 우리 학교의 행정 마스터 챗봇이야. 너의 유일한 정보 출처는 업로드된 [2026_학사일정.pdf]와 [학교생활규정.pdf] 문서야. 교사나 학부모가 질문하면 해당 문서에서 정확한 조항이나 날짜를 찾아 근거를 제시하며 정중하게 답변해 줘. 만약 업로드된 파일에 없는 내용이라면 "해당 규정은 문서에서 찾을 수 없습니다. 교무실로 문의 바랍니다."라고 단호하게 답변하여 환각(Hallucination)을 방지해.

👉 테스트: "체험학습 신청은 며칠 전까지 해야 해?", "2학기 중간고사 날짜가 언제야?" 라고 질문해 보세요. 문서 내용만 바탕으로 정확히 안내합니다.
Module 4 (심화 실습)

카톡 대화 백업으로 '내 클론 AI' 만들기 (Studio)

카카오톡 대화 내용 내보내기 파일(.txt)을 통째로 업로드하여 내 말투를 완벽 복사하기

왜 Copilot Studio를 쓰나요?
실제 카카오톡 대화 내역은 수천 줄이 넘어가기 때문에 채팅창에 텍스트로 복사해서 붙여넣기가 불가능합니다. 이럴 때 로컬 파일(.txt, .pdf 등) 직접 업로드 기능이 있는 Studio를 활용하면 방대한 양의 개인 데이터나 규정집을 한 번에 학습시킬 수 있습니다.

[실습 4-1] 첨부할 '카카오톡 백업 파일' 준비하기

방법 A: 실제 내 카톡 대화 내보내기

  1. 친한 친구와의 카카오톡 채팅방 열기
  2. 우측 상단 메뉴(三) > 채팅방 설정(톱니바퀴)
  3. '대화 내용 내보내기' > 텍스트만 보내기
  4. PC 바탕화면에 KakaoTalk_Chats.txt 저장

방법 B: 실습용 샘플 파일 만들기

개인정보가 부담스럽다면 메모장에 아래 내용을 복사해서 내_프로필.txt로 저장하세요.

[김병찬] [오전 10:30] 오키오키 확인! [김병찬] [오전 10:31] 아니 근데 진짜 대박 ㅋㅋㅋ [친구] [오전 10:35] 오늘 점심 뭐먹지? [김병찬] [오전 10:36] 그치그치 완전 공감, 난 돈까스! 넵! 바로 처리할게요~ 👍

[실습 4-2] Studio에 카톡 파일 업로드 및 클론 생성

  1. 앱 런처(점 9개)에서 Copilot Studio 접속 (또는 copilotstudio.microsoft.com).
  2. '새 Copilot' 생성 클릭 후 이름(예: [본인이름] 클론 AI) 입력.
  3. 지식(Knowledge) 탭에서 '+ 지식 추가' -> '파일(Files)'을 선택하여 방금 준비한 .txt 파일을 업로드합니다.
  4. 지침(Instructions) 입력창에 아래 내용을 복사하여 넣습니다. (본인 이름 수정 필수!)

너는 업로드된 카카오톡 대화 파일(.txt)을 완벽하게 분석하여 내 말투를 학습한 '나의 디지털 클론'이야. 업로드된 파일에서 [본인 이름 입력] 이라는 화자가 작성한 메시지의 패턴, 말투, 자주 쓰는 추임새, 이모티콘 사용 방식 등을 철저히 분석해 줘. 누군가 너에게 대화를 걸면 기계적인 AI처럼 대답하지 말고, 파일에서 추출한 내 '카톡 말투'를 그대로 흉내내서 진짜 나처럼 리얼하게 대답해야 해.

테스트 창에 말을 걸어보세요: "오늘 진짜 피곤하다 ㅠㅠ", "주말에 보통 뭐해?" 라고 입력했을 때, 내 카톡 말투와 똑같이 나오면 대성공입니다!
